These are source measurements, not shipped/minified bundle sizes, GPU-memory estimates or performance rankings. Next.js dev tooling adds overhead. Each implementation/CSS chunk is requested only when selected; Next's initial async-loader registration chunk contains import metadata, not shader implementations. Cached previously selected code can remain in browser memory. Only one selected renderer is mounted; the Original OGL and legacy library comparisons live on separate pages. Production has no gallery route or emitted gallery client code.

## Lifecycle adaptations

- Render-time settings-ref writes moved into effects preceding renderer setup/refresh, for React concurrency and the repository's refs lint rule. Public visual props retain upstream meanings.
- Silk, Orb, Light Pillar, Galaxy and Radar no longer immediately lose the still-connected context during Strict Mode effect replay. Context loss is deferred to a microtask and requires a detached canvas. Existing resource deletion remains in place.
- Magic Rings cleanup immediately marks pending shader jobs/programs for deletion instead of scheduling untracked `release` RAF polling. Detached-context release uses a microtask, avoiding a second post-unmount RAF. The shaders and variant-selection algorithm are unchanged.
- Lightning now marks its attached shaders for deletion, in addition to its existing program/buffer cleanup. Upstream retained shader references otherwise survived normal teardown until context destruction.
- Single-write canvas readiness markers are diagnostic DOM state, never React state per frame. They do not alter uniforms or drawing. Grid Distortion adds an image-load failure marker. The gallery provides a static fallback for unavailable contexts, lost contexts, React initialization errors and no-ready timeout; reset remounts the active renderer.
- Existing `useAmbientActivity` applies reduced motion, manual pause, intersection and document visibility to the selected mount. While paused/hidden/offscreen/reduced, no vendor renderer stays mounted or schedules rendering. Resuming restarts the vendor clock/seed; this is deliberately disclosed beside the preview. Static setting changes while paused affect the next mount, not a hidden GPU draw.
- Host teardown releases detached contexts as a final safety net for partial initialization. This is not a claim that every vendor allocation-failure branch individually deletes every partially allocated object. Native deletion is exercised on normal teardown; context destruction releases residual driver resources. Exhaustive allocation-fault injection remains outside this gallery audit.
- Rendering resolution uses actual `dpr`, `resolution` or `maxDevicePixelRatio` props. Grid Distortion and Soft Aurora lack public DPR controls: only their local resolution cap changes from 2 to 1. No shader string or visual algorithm changes. CSS and JSX formatting are adapted to the repository.

Normal cleanup inspection covers RAF cancellation, ResizeObserver/IntersectionObserver disconnection, window/document/canvas listener removal, image request guards and owned GL resources. The gallery additionally releases detached contexts, so experimental driver contexts cannot accumulate across switches.
