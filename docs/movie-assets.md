## Adaptations

Each backdrop comes from the public hero image on its official project page. The source URL is recorded exactly in `provenance.json`. Backdrops are resized to at most 1920px and compressed to WebP at quality 85. Portrait assets are 600×900 attention crops of those same stills. They are **poster-format presentation artwork, not official theatrical posters**. Titles are HTML interface typography; source logos and trademarks are excluded. CSS gradients improve legibility. Changes are disclosed in the footer.

No copyrighted commercial movie imagery was scraped. Only the identified, openly licensed project images were downloaded from their publisher. No film footage, soundtrack, or trailer is bundled or embedded. A trailer action is omitted because a separate trailer URL was not verified.

## Fixture policy

Synopsis copy is a concise editorial paraphrase, and genres are editorial classifications informed by the films, not a copied provider taxonomy. Only Charge and Spring have runtime values; unknown runtimes remain `null`. No scores, invented credits, popularity counts, release certifications or ratings are shown. The acclaim rail contains only the three fixtures with a linked recognition source; a selection is never described as an award win.

Trending and Popular are fixed editorial preview selections, labelled as such, not a claim of current audience activity. TMDB IDs and TMDB poster/backdrop paths have not been verified and are deliberately absent. Local asset paths are verified instead. A future NestJS adapter can map provider IDs and image URLs into the existing presentation model without changing cards.

## TMDB attribution wordmark (29 October 2026)

The user supplied the official long blue SVG at `apps/web/public/images/brands/tmdb.svg` (the actual supplied location). Windows download metadata identifies [TMDB's hosted asset](https://www.themoviedb.org/assets/v4/logos/v2/blue_long_1-8ba2ac31f354005783fab473602c34c3f4fd207150182061e425d366e4f34596.svg). An independent HTTPS request to that exact official URL returned HTTP 200, image/svg+xml and bytes identical to the supplied file. Comparison took place in memory; no additional asset copy was saved.

Original size: **2295 bytes**. SHA-256: `8ba2ac31f354005783fab473602c34c3f4fd207150182061e425d366e4f34596`, also matching the URL's content fingerprint. The file is valid SVG with viewBox `0 0 423.04 35.4`, vector paths and an internal gradient using #90cea1 / #3cbec9 / #00b3e5. Inspection found no scripts, event handlers, external resources, embedded images or foreign content. The original file remains byte-for-byte unchanged, including colors, proportions and orientation.

The existing Footer TMDB Credits section displays the external SVG as an unoptimized local image at 120 CSS pixels wide with automatic height, inside a keyboard-accessible link to https://www.themoviedb.org. Integer image dimensions are scaled uniformly from the original viewBox to preserve its exact ratio. The accessible alternative is “TMDB — The Movie Database”. Blender Credits and the non-endorsement notice remain intact. The wordmark is smaller in rendered height/area than FRAME branding; no filter, recoloring, rotation or cropping is applied.

The [official FAQ](https://developer.themoviedb.org/docs/faq) confirms use of an approved subordinate logo with the required notice in About/Credits. The [Logos & Attribution page](https://www.themoviedb.org/about/logos-attribution) remains blocked to this retrieval tool, despite the official asset being independently accessible and verified. This closes the missing-logo asset/integration condition, not a review of the full applicable agreement or permission for commercial use, movie-image redistribution, metadata snapshots or provider caching.
